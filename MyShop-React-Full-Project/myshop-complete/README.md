# MyShop — Complete React E-commerce Demo

پروژه فروشگاه آنلاین آموزشی با React، Vite، React Router و Context API.

## پیش‌نیاز
- نصب Node.js نسخه LTS
- نصب Visual Studio Code
- اتصال اینترنت برای نصب پکیج‌ها و بارگذاری عکس‌ها و فونت آنلاین

## اجرای پروژه
در VS Code پوشه پروژه را باز کن و در Terminal اجرا کن:

```bash
npm install
npm run dev
```

آدرسی را که Vite نمایش می‌دهد در مرورگر باز کن (معمولاً `http://localhost:5173`).

برای بررسی نسخه production:

```bash
npm run build
npm run preview
```

## قابلیت‌ها
- صفحه اصلی و معرفی فروشگاه
- فهرست محصولات و دسته‌بندی
- جست‌وجوی زنده محصولات
- صفحه جزئیات محصول
- افزودن محصول به سبد خرید
- افزایش و کاهش تعداد کالا
- حذف کالا از سبد خرید
- نگهداری سبد خرید در localStorage
- فرم اطلاعات تحویل و ثبت سفارش آزمایشی
- صفحه تأیید سفارش
- صفحه 404
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

## ساختار پوشه‌ها
- `src/components`: کامپوننت‌های مشترک
- `src/context`: مدیریت state سراسری سبد خرید
- `src/data`: داده‌های نمونه محصولات
- `src/pages`: صفحات مسیرهای مختلف
- `src/App.jsx`: تعریف Routeها
- `src/main.jsx`: نقطه ورود برنامه و Providerها
- `src/index.css`: استایل کلی

## نکته مهم
این یک پروژه Front-end آموزشی است. پرداخت بانکی واقعی، احراز هویت، پنل مدیریت، دیتابیس و API سمت سرور ندارد. سفارش آزمایشی فقط در مرورگر ذخیره می‌شود. قیمت‌ها و اطلاعات محصولات نمونه هستند.

## عکس‌های آنلاین
لینک عکس‌ها در `src/data/products.js` و عکس Hero در `src/components/Hero.jsx` از Unsplash هستند. می‌توانی URL هر عکس را با لینک عکس دلخواه خودت جایگزین کنی.
